# 住宿订单登记小程序

原生微信小程序项目，无后端、无网络请求。订单通过 `wx.setStorageSync` 保存在当前微信设备。

## 使用

1. 安装并打开微信开发者工具。
2. 导入本目录 `wechat-miniprogram`。
3. 当前项目使用 `touristappid` 作为本地预览占位 AppID；正式上传前，在 `project.config.json` 中替换为自己的小程序 AppID。
4. 在开发者工具中编译或预览。发布到微信需由小程序管理员完成微信平台的注册、配置和审核。

## 功能

- 按截图仅登记 10 项：旅店/订单、入住基地、客户姓名、客户电话、入住时间、入住天数、入住人数、入住房型、是否含餐、费用明细。
- 本机新增、修改、删除和搜索；旧版订单会自动转换字段并保留，不清除现有数据。
- 从首页备份菜单复制 JSON 备份，或从剪贴板导入并合并备份。
- 不调用服务器接口；清除微信小程序本地数据前，请先复制备份。

## iPhone 微信链接版

`h5/` 是可通过 HTTPS 链接在 iPhone 微信内打开的静态网页版本，适合没有小程序 AppID 时分享使用。它没有后端或数据接口，订单保存在打开链接的设备和浏览器中；不同设备、不同浏览器之间不会自动同步。GitHub Pages 自动发布目录 `h5/`；公开站点会公开网页源码，但不会包含使用者登记的数据。

链接版的旅居公司模块可单独登记公司档案，并自定义分类、按分类筛选和搜索。进入公司后管理该公司的客人入住，新增入住自动归属该公司；全部客人入口仍可跨公司查找和调整归属。公司改名保留客人关联，删除公司会把客人移到未分类并保留入住信息。

链接版把公司、分类和入住记录一并保存在本机 `inn-order-data-v2` 中；首次打开会迁移旧记录并保留原有存储。备份包含公司与客人的归属关系，兼容旧版入住备份。页面加载后可断网继续登记；首次打开和刷新页面需要加载静态文件。

正式微信小程序与 H5 链接版是两种入口。原生小程序仍需 AppID 和微信平台发布；H5 链接版无需 AppID，但需要静态 HTTPS 托管。
