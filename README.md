# 住宿订单登记小程序

原生微信小程序项目，无后端、无网络请求。订单通过 `wx.setStorageSync` 保存在当前微信设备。

## 使用

1. 安装并打开微信开发者工具。
2. 导入本目录 `wechat-miniprogram`。
3. 当前项目使用 `touristappid` 作为本地预览占位 AppID；正式上传前，在 `project.config.json` 中替换为自己的小程序 AppID。
4. 在开发者工具中编译或预览。发布到微信需由小程序管理员完成微信平台的注册、配置和审核。

## 功能

- 按截图仅登记 10 项：旅店/订单、入住基地、客户姓名、客户电话、入住时间、入住天数、入住人数、入住房型、是否含餐、费用明细。
- 本机新增、修改、删除和搜索；旧版订单会自动转换字段并保留，不清除现有数据。
- 从首页备份菜单复制 JSON 备份，或从剪贴板导入并合并备份。
- 不调用服务器接口；清除微信小程序本地数据前，请先复制备份。

## iPhone 微信链接版

`h5/` 是可通过 HTTPS 链接在 iPhone 微信内打开的网页版本，适合没有小程序 AppID 时分享使用。登记先保存在当前设备，连接同步空间后可与其他设备自动同步。网页由 GitHub Pages 托管，云端加密副本由 Cloudflare Workers 和 SQLite Durable Objects 托管，不用购买或维护服务器。公开网页源码不包含使用者登记的数据。

链接版首页主要展示旅居公司分类，可按公司或住客搜索，按待入住、入住中、已结束筛选有相关住客的公司。点击公司进入该公司的住客明细，首页不展开全部住客。主操作仍可直接新增入住登记，表单填写公司名称后自动归类。旧档案、备注、未分类记录、本机保存、备份和自动云同步保留。

链接版把公司、分类和入住记录一并保存在本机 `inn-order-data-v2` 中；首次打开会迁移旧记录并保留原有存储。备份包含公司与客人的归属关系，兼容旧版入住备份。页面加载后可断网继续登记；首次打开和刷新页面需要加载静态文件。

正式微信小程序与 H5 链接版是两种入口。原生小程序仍需 AppID 和微信平台发布；H5 链接版无需 AppID，但需要静态 HTTPS 托管。

## 多设备自动同步（链接版）

上线者需一次性注册并登录 Cloudflare 免费账号；使用登记页面的人无需注册 Cloudflare。连接步骤见 `cloud/README.md`。未连接真实云端地址时，页面明确显示“同步服务尚未连接”，创建和加入按钮不可用，本机登记与备份照常使用。

连接完成后，第一台设备在首页“数据”中创建同步空间并复制配对码。其他设备打开同一网页，进入“数据 → 加入已有空间”，粘贴配对码即可；本机已有登记也会合并。配对码可以读取、解密和修改空间内数据，只应交给共同管理者。

保存后自动上传加密修改；页面在前台时约每 20 秒检查其他设备更新，恢复联网或重新打开页面也会同步。页面关闭时不在后台运行。断网仍可登记，不同字段的修改自动合并；同一字段被同时修改时保留两份内容并提示选择。删除会传播到其他设备，旧设备不会通过普通编辑恢复已删除记录。断开同步保留本机登记。

公司、住客和归属关系使用 AES-256-GCM 在设备上加密后上传，云端只保留加密内容和修订号，不上传配对码或解密密钥。配对码保存在已加入设备的浏览器本地存储。请保留配对码与本机备份；清除所有设备的数据后无法仅凭云账号解密恢复。

当前每个空间的同步文档上限为 600,000 字节，包含版本元数据；超过上限会提示备份，本机记录仍保留。免费托管受 Cloudflare 免费套餐额度约束。
